# 🌐 Sosial Şəbəkə Platforması

Modern sosial şəbəkə platforması - dostlar tapın, paylaşın və bağlanın!

## 🚀 Xüsusiyyətlər

- 👤 Profil yaratma və idarəetmə
- 📝 Postlar/Status paylaşma
- 👥 Dostluq sistemi
- 💬 Real-time mesajlaşma
- ❤️ Bəyənmə və şərh sistemi
- 🔔 Bildirişlər
- 🔐 Təhlükəsiz autentifikasiya

## 🛠️ Texnologiya Stakı

### Backend
- **Node.js** - Server
- **Express.js** - Web Framework
- **MongoDB** - Verilənlər Bazası
- **JWT** - Autentifikasiya
- **Socket.io** - Real-time mesajlaşma

### Frontend
- **React** - UI Library
- **Axios** - API Çağırışları
- **Redux** - State Management
- **Tailwind CSS** - Styling
- **Socket.io Client** - Real-time İletişim

## 🎯 Başlamaq

### Tələblər
- Node.js (v14+)
- MongoDB
- npm və ya yarn

### Quraşdırma

1. Repozitoriyanı klonlayın:
```bash
git clone https://github.com/wkj7yy2pzd-pixel/proje.git
cd proje
```

2. Backend quraşdırması:
```bash
cd backend
npm install
```

3. Frontend quraşdırması:
```bash
cd frontend
npm install
```

4. Environment faylları yaradın (`.env`)

5. Serverləri başladın:
```bash
# Backend üçün
cd backend
npm start

# Frontend üçün (başqa terminal)
cd frontend
npm start
```
